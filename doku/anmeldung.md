# Anmeldung und Konto

Jedes Konto meldet sich mit Benutzername, Passwort und einem sechsstelligen Code aus einer Authenticator-App an. Unter **Mein Konto** verwalten Sie Passwort und Zwei-Faktor-Anmeldung selbst.

## Zugang bekommen

Ihr Administrator legt Ihr Konto an und nennt Ihnen ein **vorläufiges Passwort**. Bei der ersten Anmeldung setzen Sie ein eigenes; bis dahin sind die übrigen Seiten gesperrt.

Alternativ fragen Sie unter **Zugang anfragen** (`/registrieren`) selbst an: Benutzername (3 bis 64 Zeichen), Anzeigename und ein Passwort mit mindestens 12 Zeichen. Das Konto bleibt gesperrt, bis ein Administrator es freigibt.

## Zwei-Faktor-Anmeldung einrichten

Die Zwei-Faktor-Anmeldung ist Pflicht. Beim ersten Anmelden richten Sie sie ein:

1. Eine Authenticator-App auf dem Handy öffnen, etwa Microsoft Authenticator, Google Authenticator oder 1Password.
2. Den angezeigten QR-Code scannen. Geht das nicht, den Schlüssel darunter von Hand eingeben.
3. Den sechsstelligen Code aus der App eingeben.
4. Die **zehn Wiederherstellungscodes** notieren und sicher aufbewahren.

Danach fragt NETbrain bei jeder Anmeldung nach dem Passwort den aktuellen Code ab.

## Handy verloren oder gewechselt

- **Neues Handy, altes noch da:** Unter **Mein Konto → Zwei-Faktor-Anmeldung** auf **Neues Gerät einrichten** klicken und den neuen QR-Code scannen.
- **Handy weg:** Statt des Codes einen der Wiederherstellungscodes eingeben. Jeder gilt einmal. Danach ein neues Gerät einrichten.
- **Keine Codes mehr:** Ein Administrator setzt Ihre Zwei-Faktor-Anmeldung in der Benutzerverwaltung zurück; beim nächsten Anmelden richten Sie sie neu ein.

Unter **Neue Codes erzeugen** erhalten Sie zehn frische Wiederherstellungscodes; die alten werden ungültig.

## Passwort ändern

**Mein Konto → Passwort ändern**, mindestens 12 Zeichen. Ihr Passwort schützt auch Ihren verschlüsselten Chatverlauf; siehe [KI-Chat](ki-chat.html#verschluesselte-historie).

## Meine Beiträge

Unter **Mein Konto → Meine Beiträge** sehen Sie, was Sie als Firmenwissen eingereicht haben, mit Status: In Prüfung, Veröffentlicht, Übernommen oder Abgelehnt — bei Ablehnung samt Begründung.

## NETbrain als App

NETbrain lässt sich im Browser als App installieren (Chrome, Edge, Android; auf iOS über „Zum Home-Bildschirm“). Gespeichert werden dabei nur Programmdateien, keine Inhalte. Ohne Netz zeigt die App eine Hinweisseite.

## Tastenkürzel

| Kürzel | Wirkung |
|---|---|
| `Strg` + `K` | Suche im Firmenwissen bzw. Seitenfilter |
| `Strg` + `V` | Bild oder Bildschirmfoto einfügen (Erfassen, Bearbeiten, Chat) |
| `Enter` / `Umschalt` + `Enter` | Im Chat senden / Zeilenumbruch |
| `Esc` | Dialoge, Seitenleiste und Suchtreffer schließen |
