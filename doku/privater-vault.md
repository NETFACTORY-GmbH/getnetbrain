# Privater Vault

Der private Vault ist Ihr persönlicher Notizbereich. Die Notizen liegen als Markdown-Dateien in einem **Ordner auf Ihrem eigenen Rechner**. Auf dem Server wird nichts davon gespeichert, und niemand sonst sieht sie.

## Ordner verbinden

Beim ersten Öffnen von **Privater Vault** wählen Sie mit **Ordner auswählen** einen Ordner aus, etwa in Ihren Dokumenten. Der Browser fragt einmal, ob NETbrain darauf zugreifen darf, und merkt sich die Wahl.

> [!HINWEIS] Nur in Chrome und Edge
> Der Zugriff auf einen lokalen Ordner braucht eine Browserfunktion, die es derzeit nur in Chrome und Edge gibt. In anderen Browsern erscheint „In diesem Browser nicht verfügbar“.

Mit **Trennen** lösen Sie die Verbindung; die Dateien bleiben im Ordner.

## Notizen anlegen

- **Neue Notiz** — eine leere Notiz.
- **Privat erfassen** — wie beim Firmenwissen: Text, Link oder Datei einwerfen und auf Wunsch von der KI aufbereiten lassen. Das Ergebnis schreibt Ihr Browser in den Ordner; der Server speichert es nicht.

Anhänge liegen im Unterordner `anhaenge`. Da alles gewöhnliche Dateien sind, können Sie sie auch mit jedem anderen Editor öffnen und mit Ihren üblichen Mitteln sichern. NETbrains Sicherung erfasst sie nicht.

## Finden

Übersicht, Wissenslandkarte und **Alle Notizen** wie im Firmenwissen. Die Suche bleibt lokal in Ihrem Browser. **Im KI-Chat fragen** übergibt die Frage an den Chat.

## Im KI-Chat nutzen

Im [KI-Chat](ki-chat.html) können Sie den Vault über **Ordner verbinden** einbeziehen. Dann gehen passende Auszüge Ihrer Notizen mit der Frage an den KI-Anbieter — an Cloud-Anbieter nur, wenn Ihr Administrator das erlaubt.
